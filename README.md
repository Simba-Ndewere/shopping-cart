Shopping cart application live on https://shopping-cart-eight-ecru-34.vercel.app/

## Project Scope
The project is part of The Odin Project's JavaScript curriculum. You can view the project scope [here](https://www.theodinproject.com/lessons/node-path-react-new-shopping-cart).

## Features
- Home, shop, and cart pages
- Products fetched from an external API/Dummy Json [here](https://dummyjson.com/docs)
- Add products to cart
- Real-time cart quantity shown in the navbar
- Cart page displaying selected items and quantities
- Increase, decrease, or remove items from cart
- Component-based architecture
- Responsive layout for mobile, tablets and desktop
- Persistent UI state

## Technologies Used
- JSX
- CSS
- JavaScript
- React
- React-router
- Vite
